# 마크다운 샘플 파일

- 굵게: **굵은 글씨** 표시하기
- 기울임: *기울인 글씨*
- 굵게 + 기울임: ***둘 다 적용***
- 취소선: ~~취소된 글씨~~
- 인라인 코드: `console.log("hi")`

## 코드 블록

```js
function greet(name) {
  return `안녕, ${name}!`;
}
```

```python
def greet(name):
    return f"안녕, {name}!"
```

## 표

| 문법 | 설명 | 비 고 |
| --- | --- | --- |
| `**굵게**` | 굵은 글씨 | 참고1 |
| `*기울임*` | 기울인 글씨 | 참고2 |
| `` `코드` `` | 인라인 코드 | 참고3 |
| `` `코드2` `` | 인라인 코드2 | 참고4 |
